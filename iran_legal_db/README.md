# بانک اطلاعاتی حقوقی کامل ایران 🇮🇷⚖️

یک پایگاه داده **SQLite توسعه‌پذیر** برای نگهداری همهٔ انواع اسناد حقوقی ایران:
قوانین، اصلاحیه‌ها، آیین‌نامه‌ها، آرای وحدت رویه، نظریات مشورتی، بخشنامه‌ها،
و آرای دیوان عدالت اداری؛ به‌همراه **تاریخچه تغییرات هر ماده** و **ارتباطات بین اسناد**،
همراه با **وب‌اپلیکیشن فارسی (RTL)** برای جست‌وجو و مرور.

## ✨ ویژگی‌ها

- **همه ۸+ دسته سند** از پیش‌تعریف‌شده: قانون، قانون اساسی، قانون اصلاحی، آیین‌نامه،
  بخشنامه، دستورالعمل، رأی وحدت رویه، نظریه مشورتی، رأی دیوان عدالت اداری،
  اساسنامه، رأی اصراری/رویه قضایی، معاهده بین‌المللی.
- **تاریخچه ماده‌ها**: هر ماده می‌تواند چند نسخه (`version_no`) داشته باشد؛
  نسخه فعلی (`is_current=1`) و نسخه‌های قبلی با `effective_date` / `expiry_date` + `article_key` پایدار.
- **شبکه ارتباطات اسناد**: انواع رابطه (`amends`, `abrogates`, `implements`,
  `cites`, `interprets`, `ruled_by_divan`, `overrules`) هم در سطح سند و هم در سطح ماده.
- **دسته‌بندی موضوعی** (حقوق مدنی، کیفری، تجارت، خانواده، کار، مالیات، اداری، …) + **برچسب** + **جست‌وجوی تمام‌متن (FTS5)**.
- **شناسنامه کامل اسناد**: مرجع صادرکننده، تاریخ تصویب/انتشار/اجرا، شماره روزنامه رسمی، کد یکتا، منبع.
- **وب‌اپ فارسی RTL** با جست‌وجوی زنده، فهرست درختواره، نمایش ماده و تاریخچه.

## 🌐 تصویر کلی وب‌اپ

- صفحه اصلی: آمار + جست‌وجو + دسته‌بندی اسناد + آخرین اسناد
- `/types` – انواع ۱۲‌گانه اسناد با شمارنده
- `/by-type/<code>` – فهرست اسناد هر دسته
- `/doc/<id>` – صفحه سند (شناسنامه + شمارش پوشش + متن جاری/تاریخی/همه نسخه‌ها + ارتباطات ورودی و خروجی)
- `/article/<id>` – صفحه ماده (متن + تاریخچه نسخه‌ها + ارتباطات)

## 🧩 افزودن سند جدید (در چند خط)

به سادگی از الگوی `scripts/add_document_template.py` استفاده کنید.
انواع `type_code`:

| code | معنی |
|---|---|
| `constitution` | قانون اساسی |
| `law` | قانون عادی |
| `amendment` | قانون اصلاحی |
| `regulation` | آیین‌نامه |
| `bylaw` | اساسنامه / آیین‌نامه داخلی |
| `circular` | بخشنامه |
| `directive` | دستورالعمل / شیوه‌نامه |
| `unified_ruling` | رأی وحدت رویه |
| `advisory_opinion` | نظریه مشورتی |
| `divan_ruling` | رأی دیوان عدالت اداری |
| `judicial_precedent` | رأی اصراری / رویه قضایی |
| `treaty` | قرارداد/کنوانسیون بین‌المللی |

برای **تاریخچه اصلاحات یک ماده**، نسخه قبلی را با `expiry_date` بایگانی و نسخه جدید را با `version_no = n+1`, `article_key = QM:10` (کلید پایدار) و `is_current=1` اضافه کنید (دمو در `demo_amendment.py`).
