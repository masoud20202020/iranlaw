## ۴. الگوی ثبت تاریخچه تغییرات هر ماده

برای هر ماده که در طول زمان اصلاح، نسخ یا جایگزین شده است:

1. رکورد قبلی ماده را با `is_current = 0` و `expiry_date = تاریخ اجرای اصلاحیه` به‌روزرسانی کنید.
2. رکورد جدید با `version_no = n+1`، `is_current = 1` و `effective_date = تاریخ اجرای اصلاحیه` ایجاد کنید.
3. یک رابطه از نوع `amends` بین سند اصلاحی و سند اصلی (با شناسه ماده) ثبت کنید.
4. یک رابطه توضیحی (description) یادداشت کنید (مثلاً «ماده ۱۰ اصلاحی ۱۴۰۳/۴/۱۵، جایگزین ماده ۱۰ مصوب ۱۳۰۷»).

برای ثبت نسخ نیز همین الگو تکرار می‌شود با این تفاوت که نسخه فعلی باقی نمی‌ماند و ماده
`is_current = 0` شده و `expiry_date` درج می‌شود.
